## 整理范围

- 从正文中选录完整短篇或一个章节，去除电子书目录、平台页首页尾与许可附录；示例文本内不使用来源平台的品牌标识。
- 添加 Markdown 标题、作者说明，保留原文文字与段落。镜花缘和 Alice 保留电子底本的行折断。
- 《聶小倩》底本含两个私用区字符 U+E012、U+E262，各出现一次，分别替换为 `〔缺字：U+E012〕`、`〔缺字：U+E262〕`；未猜补原字。其他文字未经校勘，可能仍有录入异文。
- 作者说明所在的聊斋首页也会被阅读器列为一章，所以书架显示四章，即说明页加三篇故事。镜花缘与 Alice 各一章。
- TXT / Markdown 导入目前不会从正文提取作者字段，书架显示“未知作者”；作者信息可在本文和示例正文中查看。

## 入门体验

先导入聊斋选篇完成阅读，再通过书架的「导入并关联世界书…」导入 [聂小倩入门设定](../聂小倩.lorebook)。此 Lorebook 只含五条手工设定，没有模型自动分析结果，也不含截图中的游玩回合或存档。

继续互动与工坊分析需要配置自己的模型服务，可能产生费用。全文分析可在熟悉流程后自行尝试；入门展示不要求分析整部小说。
