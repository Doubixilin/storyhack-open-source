# 内置素材与测试来源

`source/` 保存项目生成的虚构叙事样例与合成评测输入，包含选择、判词、状态文案、文风样例和角色原型。它们不是从用户导入小说提取的语料。随项目按 MIT 许可提供；不包含私人图书库或内部模型请求记录。

运行资源位于 `Sources/StoryMaterialKit/Resources/materials-v1/`。`scripts/material_compiler.py` 将源 JSONL 按格式与计数规则编译为分片资源，并把不满足约束的状态文案放入 quarantine。编译与加载测试不等于文学质量评估，素材增强默认关闭。

`test_inputs.jsonl` 及 `Tests/` 中的对应夹具包含虚构角色、冒险情境和故意不合规 / 注入式输入，用于稳健性测试，不能作为产品推荐内容或安全保证。真实模型 A/B 测试只在显式启用后运行。

演示小说、演示世界设定和项目图标随源码提供。新增素材请注明生成 / 创作方式或授权来源；不要加入未获授权的小说正文、用户聊天、密钥或完整请求响应。
