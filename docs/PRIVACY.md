# 隐私与数据边界

## 本地保存

书籍、世界设定、角色、写作项目、改编任务、存档和分支主要保存在设备上的应用数据目录。Mac 默认根目录为 `~/Library/Application Support/StoryhackCommunity/`；iOS 使用应用自己的沙盒。模型配置保存在 `Providers/`，API Key 使用 Keychain 服务 `org.doubixilin.storyhack.community.llm`。应用标识为 `org.doubixilin.storyhack.community`。

社区版不自动访问原版 `WorldbookApp` 数据根目录与密钥服务。原版与社区版交换设定请手动导出 / 导入。`.storyworld` 包可能包含游玩记录；分享前自行检查内容。

没有内置分析统计 SDK、账号服务或远程 HTTP 服务。文件没有额外的应用层加密；设备权限、磁盘加密与备份保护仍由系统及使用者负责。隐私模式只在 App 失去前台焦点时遮挡界面，不会加密文件。

## 模型请求

阅读与手动编辑无需访问模型服务。启用互动叙事、世界书工坊、改编或写作功能时，会向你配置的 Base URL 发送请求。根据功能，请求可能包含小说片段、世界设定、角色资料、用户输入、选定历史与写作草稿。费用、留存和训练政策由服务提供方决定；本项目无法替服务方保证保密。

模型配置只允许 HTTPS；HTTP 仅用于本机回环地址的开发 / 测试。提交问题前请删除 API Key、私人正文、Authorization 和完整请求响应。任务目录、缓存与备份可能保留输入和模型输出，请按私人内容处理。

## CLI 与分享

任务 CLI 默认使用社区版数据目录，可用 `--root` 显式改为测试目录。凭据只读取 `WORLDBOOK_API_KEY`，不会写入 Keychain。不要将密钥直接写进命令参数、脚本、仓库或问题报告。

模型输出不等于事实或内容质量保证。分享导入作品、改编文本、角色图片或模型输出之前，请确认自己拥有相应权利。
