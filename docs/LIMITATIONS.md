# 当前限制与下一步

0.1.0 是开发者预览。自动测试通过意味着对应的代码路径符合测试断言，不代表所有小说、所有模型或所有设备已经验收。

- 导入支持文字型 TXT、Markdown、EPUB。没有 PDF / OCR；复杂 EPUB 排版和异常编码仍可能需要处理。
- TXT / Markdown 当前不会自动提取作者。公版全文的篇名、罗马数字和特殊格式可能无法正确识别为章节；随附选录已用 Markdown 标题整理。古典电子底本可能含缺字或异文，来源与整理记录见 [公版示例说明](../Examples/PublicDomain/README.md)。
- AI 功能要求使用者提供兼容模型服务。不同服务的流式输出、上下文长度、结构化回答与工具调用能力有差异，可能导致重试或失败。
- iOS 工坊需前台运行，不承诺系统后台持续执行。iOS 尚未开放完整写作 / 改编界面。
- 内置素材为生成的叙事样例；素材增强默认关闭，仍需要真实质量评测。数据条数不能证明文学质量。
- 生图工作区保留实验代码，入口尚未开放；不将其描述为已完成的生图功能。
- 存档、草稿和任务有恢复与版本检查机制，仍建议定期备份。暂不提供云同步或多人协作。
- 社区版不包含远程浏览器服务。若以后加入，须先明确配对、鉴权、撤销与跨入口写入规则。
- 当前没有官方签名、公证的安装包，没有 App Store 分发；iPhone 真机与真实付费模型仍需另行验收。

下一步按以下顺序推进：

1. 在干净机器和真实 iPhone 上验证导入、保存、恢复、分支与升级。
2. 用原创 / 获授权文本覆盖不同小说长度与模型，对结果质量和成本分别记录。
3. 完善首次使用、错误恢复与备份说明，再决定签名安装包的发布流程。
4. 依据真实反馈修复问题；新 AI 功能与远程访问另行评估。
